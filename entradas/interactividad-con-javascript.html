Dando vida a la página con JavaScript

Publicado el 24 de noviembre de 2026

Cierro esta pequeña serie de entradas con JavaScript, el lenguaje de programación que permite que una página web deje de ser un documento estático y pueda reaccionar a lo que hace el usuario: un clic de ratón, enviar un formulario, filtrar contenido en vivo o recordar sus preferencias.

¿Qué aporta JavaScript que no tienen HTML y CSS?

HTML aporta la estructura y CSS el aspecto visual, pero ninguno de los dos puede por sí solo calcular valores, validar lo que el usuario escribe, pedir datos al servidor sin recargar toda la página o guardar preferencias en el navegador. Para todo eso usamos JavaScript, que se ejecuta directamente en el cliente.

¿Cómo hemos aplicado JavaScript de forma real en este blog?

En lugar de poner un botón ficticio que no sirva para nada, en este blog hemos utilizado JavaScript para resolver problemas reales del desarrollo web:

  • 1. Variables globales del autor y del blog: En lugar de escribir el nombre del autor o la descripción repetida en cada archivo HTML, definimos una variable en script.js y JavaScript rellena automáticamente esos datos en toda la web.
  • 2. Carga dinámica de entradas (Fetch y JSON): La portada ya no tiene los enlaces escritos a mano. Mediante fetch("entradas.json"), JavaScript lee la lista de artículos y genera las tarjetas dinámicamente con un bucle.
  • 3. Buscador en tiempo real: En la portada, el evento onkeyup analiza lo que escribe el usuario y oculta las entradas que no coinciden en tiempo real.
  • 4. Sistema de "Me gusta": El botón al final de cada artículo incrementa un contador interactivo en pantalla manipulando directamente el DOM con JavaScript.

Ejemplo: cómo inyectamos las variables del autor en el DOM

// Variables de configuracion centralizadas
var configBlog = {
    autor: "Estudiante de DAR",
    bio: "dando sus primeros pasos en desarrollo web..."
};

// Rellenamos todos los elementos con la clase "nombre-autor"
var autores = document.getElementsByClassName("nombre-autor");
for (var i = 0; i < autores.length; i++) {
    autores[i].innerText = configBlog.autor;
}

Lo que he aprendido en esta primera toma de contacto

  • El DOM (Document Object Model) es la representación en memoria del árbol HTML que JavaScript puede consultar y modificar en tiempo real con métodos como document.getElementsByClassName(...) o innerHTML.
  • La API Fetch permite hacer peticiones asíncronas para cargar datos (archivos JSON o respuestas de un servidor) sin tener que recargar la página completa.
  • Los eventos (como onclick u onkeyup) nos permiten escuchar las acciones del usuario y ejecutar funciones que actualizan la interfaz al instante.
